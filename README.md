# ALIF VESNA KIDS

Yangi oʼzbek alifbosi (29 harf: Ç, Ğ, Ö, Ş, ʼ) asosidagi bolalar o‘yinlari, yorqin dizayn va 3D sfera.

## Run locally

```bash
npm install --legacy-peer-deps
npm run dev
```

## Check

```bash
npm run lint
npm run build
```

Build natijasi `dist/` papkada. Render uchun: build `npm install --legacy-peer-deps --no-audit --no-fund && npm run build`, publish `dist`.
